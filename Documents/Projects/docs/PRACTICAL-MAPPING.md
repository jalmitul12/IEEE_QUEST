# Academic Requirement Mapping — Aegis

## Practical 1 — JavaScript + Node.js + JSON file creation

- Embedded JavaScript: `public/system-check.html` contains legitimate browser diagnostics logic inside a `<script>` tag.
- Node runtime: the complete backend runs on Node.js + Express.
- `scripts/script.js`: prints the literal **Hello world** plus the Aegis server name.
- `scripts/app.js`: creates an Aegis JSON object and stores it in `data/output.json` using Node's `fs` module.

Run:

```bash
npm run hello
npm run json-write
```

## Practical 2 — JSON handling

- JSON object display: `scripts/display.js`
- External JSON read + `JSON.parse()` / `JSON.stringify()`: `scripts/read-json.js`
- Multidimensional JSON array and nested element access: `scripts/multi-dimensional-JSON-display.js`
- JavaScript + JSON manipulation application: `/app/preparedness`
  - add
  - edit
  - complete
  - delete
  - filter
  - completion percentage
- The real backend also reads/writes `disasters.json`, `shelters.json`, `teams.json`, `incidents.json`, `alerts.json`, tasks and settings using Node `fs`.

## Practical 3 — Responsive web design

- Every HTML page has:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

- `public/css/main.css` uses responsive width and max-width containers.
- Landing/awareness pages use a real `<picture>` element and different mobile/desktop image sources:
  - `public/assets/aegis-response-wide.svg`
  - `public/assets/aegis-response-mobile.svg`
- Responsive typography uses `clamp()` and explicit `vw` sizing such as `.responsive-demo-title` on small screens.
- CSS media queries cover desktop/tablet/mobile layouts.
- Large command-center navigation becomes a mobile drawer rather than disappearing.
- Wide incident lanes remain horizontally scrollable on small screens.

## Practical 4 — Geolocation, Local Storage, Drag & Drop

### Geolocation API

Used in:

- `/app/map`
- `/app/shelters`
- `/app/evacuation`
- `/app/sos`
- top command-center location chip

Uses `navigator.geolocation.getCurrentPosition()` and handles:

- permission denied
- unavailable location
- timeout
- unsupported browser
- manual latitude/longitude fallback

### Local Storage

Used for safe frontend information only:

- remembered email (optional)
- settings cache
- preparedness task cache
- optional remembered location

Passwords and JWT authentication tokens are **not** stored in Local Storage.

### Drag and Drop API

`/app/incidents` uses real browser drag events:

- `dragstart`
- `dragover`
- `drop`

Incident workflow:

```text
Reported → Verified → Team Assigned → Responding → Resolved
```

Status changes persist to the JSON backend. Operator authorization is required.

## Practical 5 — Bootstrap online + offline + registration

### Bootstrap online/CDN

`public/register.html` loads Bootstrap 5.3.3 from jsDelivr with an integrity hash and uses Bootstrap grid/form classes for:

- full name
- roll number / user ID
- mobile
- email
- address
- city
- state
- password and confirmation

### Bootstrap offline/npm

`public/resources.html` loads:

```text
/vendor/bootstrap/css/bootstrap.min.css
```

The server exposes that path from the locally installed `bootstrap` npm package.

## Practical 6 — Tailwind CSS

Tailwind CSS is implemented in two deliberate ways:

- `public/awareness.html` uses the **Tailwind Play CDN** on a public, non-authenticated academic feature page.
- Login and selected command-center pages load the locally compiled `public/css/tailwind-aegis.css`, generated by `scripts/build-tailwind.js` from the pinned `tailwindcss` package. This keeps third-party runtime JavaScript away from credentials and protected pages.

`public/awareness.html` naturally incorporates the supplied exercises:

- hover background/text transitions
- selectable Tailwind text sizes
- image effects such as rounded, circle, shadow, grayscale, sepia, blur, brightness, contrast, saturation, opacity, rotate, zoom, ring and border
- a working emergency-preparedness reference form with book title, author name, publisher name, published year, ISBN/reference ID and quantity

The login page uses locally compiled Tailwind spacing, flex/grid, focus ring, hover/transition and shadow utilities.
